# Acceptance Checklist – 33 d-block Cohesive-Energy Datapoints
**Must be published before work begins. Every item required.**

## Per datapoint

- [ ] Primary source is peer-reviewed paper or authoritative handbook
- [ ] Full citation + DOI / stable URL provided
- [ ] Exact table / page / figure / equation location given (locatable in < 60 s)
- [ ] Numeric value transcribed exactly (including significant figures)
- [ ] Unit stated and matches source (or conversion shown + justified)
- [ ] Uncertainty reported exactly as in source **or** explicit “uncertainty not reported” with confirming location
- [ ] Two independent reviewers (no shared affiliation/funding with each other or worker)
- [ ] Reviews performed in parallel, not sequential
- [ ] Each reviewer has signed the Independent Reviewer Declaration
- [ ] Worker has not claimed this datapoint in any prior epoch
- [ ] Evidence submitted before epoch deadline
- [ ] Publisher (multi-party) final human acceptance recorded

**Fail any item → reject. No partial credit.**
